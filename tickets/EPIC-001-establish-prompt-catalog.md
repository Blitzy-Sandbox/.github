# Establish a community-accessible prompt catalog for Sandbox contributors

## Epic Summary

Establish a community-accessible prompt catalog that enables Blitzy Sandbox contributors to discover, evaluate, and contribute reusable prompt patterns, accelerating prompt reuse across Sandbox projects and reducing time-to-first-successful-generation. The catalog directly realizes the "Prompt catalog with examples and snippets" roadmap item documented in [`../profile/README.md`](../profile/README.md) (Roadmap section). Scope is bounded to defining the catalog schema, contribution workflow, and an initial seed of six entries; it does not include automated catalog hosting, search infrastructure, or moderation tooling.
